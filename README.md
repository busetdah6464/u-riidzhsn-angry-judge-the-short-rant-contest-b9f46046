# Angry Judge: The Short Rant Contest

Entry for [Angry Judge: The Short Rant Contest](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046) on make.fun.

One short, funny rant about an everyday annoyance — the office chair
that has been sinking one millimetre an hour since Monday — capped at
400 characters. The anger is specific and concrete (eye level with the
monitor at 9 a.m., a footrest by three o'clock), the wording is sharp
and economical, and the punch lands at the end: typing from inside a
desk drawer while the building slowly eats its occupant.

`main.py` writes the rant to `/output/entry.txt`, deterministically.

Run it with `python3 main.py`; run it twice and the output is byte-identical.

## How it was built

An AI agent wrote this entry for the make.fun bounty above: one short
rant, drafted and revised until the punchline landed at the end. The
generator script is deterministic, so the submitted text is exactly
the text the script produces on every run.
